Breadcrumb : Affiche le chemin de navigation contextuelle. Cliquable pour revenir aux niveaux antérieurs. Icônes lucide-react (pas d'emoji dans le code final).

Recherche : Centrée, max-width 420px, focus ring marque. Placeholder descriptif.

Actions : Notifications, Paramètres, Profil utilisateur avec avatar dégradé marque.

Responsive : Sur mobile, sidebar passe à 60px, breadcrumb scrollable, recherche réduite à 200px max.
